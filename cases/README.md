## 行号约定（expectedContext 键 `<文件路径>:<行号>`）

- **正数行号**：修改前已存在的函数，行号 = 该函数在 `originFile`（修改前文件）中的起始行（1-based）。
- **负数行号**：该 commit 新增的函数（修改前文件不存在），绝对值 = 该函数在修改后文件中的起始行。
